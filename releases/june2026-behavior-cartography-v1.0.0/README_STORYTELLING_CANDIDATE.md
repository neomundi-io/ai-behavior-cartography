# NeoMundi — Public behavior storytelling cartography candidate

## Status

**Candidate pending human review.**

## Public doctrine

This release publishes behaviors, not systems.

It contains:
- no provider name;
- no model name;
- no internal system name;
- no pseudonym;
- no profile-level row;
- no system-level point;
- no exact per-question regime count;
- no ranking;
- no score.

## Interpretation boundary

This public candidate does not create:
- provider rankings;
- quality grades;
- deployment recommendations;
- pseudonymised profiles;
- system-level points;
- exact per-question regime counts;
- semantic-equivalence claims;
- causal claims about intrinsic model properties alone.
